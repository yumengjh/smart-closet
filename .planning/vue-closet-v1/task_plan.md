# 数字衣柜 Vue 首版实现

## 目标
在 `smart-closet` 建立 Vue 3 数字衣柜，并在 `smart-closet-server` 补齐认证、数据隔离和衣物管理 API，达成首版计划。

## 阶段
- [x] 1. Vue 可交互原型：登录、衣柜、录入、待确认、详情、任务、我的、回收站；Ant Design Vue 主题和响应式布局。
- [x] 2. 后端：认证/账号管理、owner 归属和历史迁移、产品列表/确认/回收站、每日额度与模型许可。
- [x] 3. 前后端联调、启动说明、前端构建与后端回归验证。

## 固定决策
各用户独立衣柜；管理员建号与首次改密；最终采用浅灰白背景、黑色主操作与蓝色活动标记（根据后续体验反馈替换最初暖米白松绿方向）；JPEG/PNG单件录入；AI识别整理默认；用户确认入柜；AI每日20次；本机和局域网；先模拟原型后接真实 API；正式运行默认真实模式，显式演示模式禁止模型提交。

## 风险与边界
- 后端工作区已有用户未提交改动，所有变更须沿用现状，不能重置/覆盖。
- 后端既有用户、任务、衣物、文件及独立分割数据都需归属校验。
- 用户接口与图片 URL 必须共同鉴权；队列任务需能持久化 owner。
- UI 原型不能让模拟数据/付费操作被误认为真实结果。
