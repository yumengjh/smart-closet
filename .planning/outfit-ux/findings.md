# 实施发现

- PRODUCT.md 明确 Ant Design Vue、清晰克制可靠、手机与桌面同等重要。
- 组合台大量独立原生按钮、搜索与 select 使用松绿/米色和 9–12px 字号，偏离现有主题。
- 移动端只有前移/移除等少量工具，右侧属性区隐藏后无法分组/精调/替换；两层底栏挤占画板。
- canvasArea 的 ResizeObserver 只在初次 mounted 注册，列表进入新建时未正确附着；应随元素 ref 生命周期注册。
- /api 使用 Vite 代理到 8080，真实后端和现有 H2 正在运行。
- ego-browser 验收空间 6，p1 初次导航重定向到真实登录页，需真实认证后验证。
- 独立真实 QA 后端 8081 使用既有隔离 H2，未修改主服务 8080 的账号和衣物；5174 仅供本轮自动验收，结束后关闭。
- Konva 右键同样触发 click，菜单在 mouseup 后被 stageClick 关闭；需按原生 button 忽略非左键 click，已用真实鼠标事件复测。
- 双指事件必须在画板容器捕获阶段处理，避免 Transformer 抢先识别为缩放衣物；触控模拟验证画板 156% 时浏览器仍为 100%。
- 320/390/768/1024/1280/1440 六档检查无横向溢出，衣柜和属性仅桌面展示；320px 工具栏将帮助收进“更多”。
- 已实测拖入落点、右键层级/信息/移除、撤销重做、云端保存再读、移动角度精调、长按、原生触控拖动、草稿刷新和返回恢复、1080×1350 PNG 导出。
- 触屏验证采用 Chromium 触控模拟，未进行实体手机验收。

## 第二轮空间诊断

- 1440×900 实测旧白板只有 419×524，页面高度 924，编辑时仍会滚动整页。
- 全局侧栏 224px，顶栏、标题与工具栏重复占用；三张带边距的面板继续缩小画板。
- 缩放上限以适应屏幕倍率计，fit 又被 0.6 硬限。flex + auto margin 的画板定位与浏览器滚动混在一起，缺少稳定的工作区和鼠标锚点。
- 改为视口内独立编辑壳、56px 顶栏、可折叠工具面板和可平移工作区。画板逻辑尺寸及保存数据不变。
- 新布局 1440×900 实测画板 573×716，宽高各增加约 37%，画板面积约增加 87%。320/390/768/1024/1440 无整页横向或纵向滚动。
- 原生 Ctrl + wheel 放大 143%，鼠标锚点误差小于 1px，浏览器缩放保持 1；Shift 横移、普通滚轮、空格和中键平移均实测有效。
- 移动触控模拟 160% 缩放，双指等距移动视图 (-40, -30)，不触发浏览器缩放。视图操作前后场景数据一致，放大及平移后仍导出完整 1080×1350 PNG。
- 调整屏宽后立即点击的浏览器定位曾命中旧布局按钮，重新观察响应式稳定状态后成功；无业务错误。空格曾被聚焦的工具按钮拦截，已允许鼠标停在工作区时激活空格平移，输入框仍保留空格输入。
