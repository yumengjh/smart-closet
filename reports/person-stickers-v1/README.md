# 人物贴纸 v1

状态：用户已确认素材，三套人物贴纸已接入正式画板及 v2 保存。旧底座与骨架已撤回，通用按钮间距修复保留。

- 内置 imagegen 生成三套透明部件图；手绘版经一次风格简化修订。
- 每套 14 张独立 PNG，位于对应 `parts/` 目录；未改绘图片，提取时裁去图集单元格透明边距，保留原始 alpha。
- `composites-overview.png` 为这些实际部件经缩放、叠放生成，非另行生成的完整人物。
- 各套 `parts-overview.png` 提供部件对照；`source-atlas.png` 保留最终源图。
- `generation.json` 记录工具、完整提示词及来源；`parts-manifest.json` 记录各部件尺寸。
- 头、颈肩、躯干和手臂有可见重叠轮廓；当前没有隐藏接缝或自动关节。

使用：在搭配台切换到“人物贴纸”，选择套装或零散部位，逐件点选或拖入。人物贴纸可以重复加入，与衣物共用调整面板和图层。

支持：复制、翻转、裁剪、等比缩放、自由拉伸、移动与旋转，以及共同撤销、草稿恢复、保存、重新打开、缩略图和 PNG 导出。详见 `verification.md`。
