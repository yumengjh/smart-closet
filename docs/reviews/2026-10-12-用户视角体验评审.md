# 2026-10-12 用户视角体验评审与极简模式

issue：front #19 · 配套功能：front #18、server #42

## 方法

在本地起一套完整环境（后端 H2 + 真实模型网关配置，前端 Vite），用一个新账号从首次登录开始，按普通用户的路径走：改密 → 添加衣物 → 衣柜 → 组合台保存搭配 → OOTD → 「我的」。桌面 1440×900 与手机 390×844 各截一遍，记录每一处「需要停下来想一想」或「要读一大段字才知道怎么做」的地方。截图在 [2026-10-12-assets](2026-10-12-assets/)。

### 评估后暂不改

| 观察 | 原因 |
| --- | --- |
| 组合台在衣柜为空时同时显示「今天穿什么」的空提示和画板空状态 | 推荐卡片的空提示带具体原因（缺上下装），删掉会丢信息；等推荐区改版时一起处理 |
| 「我的」菜单对管理员有 12 项 | 普通用户只看到 8 项；管理员项后续可以收进一个「管理」分组 |
| 手机底栏没有 OOTD | 底栏固定五格（中间是添加），加第六格会挤；先从组合台进入，观察使用频率再定 |

## 极简模式

- 入口：顶栏的「≡」按钮（开启后变为「—」并高亮），保存在当前浏览器（`yuda.minimal.v1`），与深浅主题一样不跟账号走。
- 实现：`stores/preferences.ts` 在 `<html>` 上设置 `data-density="minimal"`；纯文字的隐藏统一写在 `style.css` 末尾一组规则里（副标题、眉题、设置分组说明、提示与脚注、画板快捷键提示），结构性的变化由页面读 `minimal` 决定（OOTD 页隐藏「只检查搭配」、检查明细只在有阻断时显示、动作卡默认收起只留「自动」）。
- 不隐藏：错误、警告、额度与确认弹窗、任何会改变数据的操作入口。
- 注意：Vue scoped 样式里的 `:global(html[...]) .x` 会被编译成只剩 `html[...]`，等于把整页隐藏（开发时踩到过）。全局规则一律写进 `style.css`。
